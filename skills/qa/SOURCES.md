# Sources

Aggregated and edited from three MIT-licensed collections (read at the commits listed):

- [proffesor-for-testing/agentic-qe](https://github.com/proffesor-for-testing/agentic-qe) `e5814a2`, Dragan Spiridonov: context-driven testing, SFDIPOT, exploratory testing, test idea rewriting, testability, risk, shift-left/right, regression, bug reporting, review rubric.
- [petrkindlmann/qa-skills](https://github.com/petrkindlmann/qa-skills) `b3bb61b`, Petr Kindlmann: strategy, planning, risk, exploratory sessions, unit testing, coverage, test data, reproduction, triage, reliability, curation, test cases, release readiness, postmortems, metrics.
- [Marina-Gajego/qa-skills](https://github.com/Marina-Gajego/qa-skills) `9c7450b`, Marina Gajego: bug report writing and severity rules.
- A colleague's team playbook for verifying tickets: result classification, done criteria, summary template, change-to-regression map, shared-environment and E2E rules.
- FEW HICCUPPS checked against [Michael Bolton's original list](https://developsense.com/blog/2012/07/few-hiccupps); the source collections expanded it inconsistently.

Dropped from the sources: vendor and tracker setup, the agent-fleet machinery, marketing figures (claimed time savings, prediction accuracy), a review scoring scheme with broken arithmetic, and cost-of-defect multipliers with no traceable source.
